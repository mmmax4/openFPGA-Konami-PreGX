# Contributing

Report the game/revision, core build, Pocket OS and exact scene. Screenshots
or short clips are useful; do not upload game ROMs, EEPROM dumps, saves or
private conversations. Keep inherited copyright/license notices.

Support and qualification are per game. Planned profiles must not be exposed
as playable until integrated and tested. Changes to video should exercise
actual pixels, priorities, memory latency and line deadlines; changes to audio
should use original samples/traces. Preserve a failing source-bound fixture
before a fix and rerun it against the repaired source. A passing simulation
does not substitute for a fitted timing review or real Pocket testing.
